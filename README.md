# Portafolio Personal — Evans Jiménez

Portafolio personal desarrollado para presentar mi experiencia profesional, conocimientos técnicos, formación académica y proyectos relacionados con la Ingeniería de Software, el Análisis de Datos y la Inteligencia de Negocios (Business Intelligence).

## Descripción del Proyecto

Este proyecto fue desarrollado para mostrar mi perfil profesional mediante una interfaz web moderna, interactiva y adaptable a diferentes dispositivos.

El portafolio incluye secciones dedicadas a mi perfil profesional, conocimientos técnicos, experiencia laboral, educación y medios de contacto.

## Características

* **Diseño responsivo:** Interfaz adaptable a computadoras, tabletas y dispositivos móviles.
* **Navegación interactiva:** Barra de navegación para acceder a las diferentes secciones del portafolio.
* **Conocimientos técnicos:** Presentación de lenguajes de programación, frameworks, bases de datos y herramientas de inteligencia de negocios.
* **Experiencia profesional:** Descripción de puestos anteriores, responsabilidades y aportes técnicos.
* **Formación académica:** Presentación de estudios y formación educativa.
* **Formulario de contacto:** Integración con EmailJS para facilitar la comunicación por correo electrónico.
* **Animaciones:** Transiciones y efectos visuales implementados mediante Framer Motion.
* **Navegación entre secciones:** Acceso a las distintas secciones del portafolio mediante navegación del lado del cliente.

## Tecnologías Utilizadas

| Tecnología    | Propósito                                            |
| ------------- | ---------------------------------------------------- |
| React         | Desarrollo de interfaces de usuario                  |
| Vite          | Servidor de desarrollo y herramienta de compilación  |
| JavaScript    | Lógica e interactividad de la aplicación             |
| Tailwind CSS  | Estilización mediante clases utilitarias             |
| CSS           | Diseño y estilos personalizados                      |
| Framer Motion | Animaciones y transiciones                           |
| React Router  | Gestión de rutas y navegación                        |

* **Lenguajes de programación:** C#, JavaScript, Python y SQL.
* **Desarrollo Front-End:** React, HTML y CSS.
* **Desarrollo móvil:** Flutter y Dart.
* **Bases de datos:** Microsoft SQL Server y MySQL.
